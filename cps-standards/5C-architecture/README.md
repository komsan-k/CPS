# 🧩 Standard Collection Based on the 5C Architecture

## 📘 Concept

The paper organizes international CPS standards according to the 5C architecture:

**Connection → Conversion → Cyber → Cognition → Configuration**

👉 This creates a layered standard ecosystem, where each level:
- has a specific technical role, and  
- is supported by dedicated standards  

✔ Ensures interoperability, scalability, and industrial implementation in Industry 4.0  

---

# 🏛️ 1. C1 — Connection (Smart Connection Level)

## 🎯 Role
Acquire data from the physical world (machines, sensors, devices)

## 🔧 Functions
- Sensors & actuators  
- Data acquisition  
- Device identification  
- PLC-based control  

## 📜 Key Standards
- ISO/IEC 19762 → AIDC terminology  
- ISO/IEC 15459 → Unique identification  
- ISO/IEC/IEEE 21450 / 21451 → Smart sensors  
- IEC 61131 → PLC systems  
- IEC 61499 → Distributed control  

## 🧠 Insight
Data entry point of CPS:
- Real-time sensing  
- Standardized communication  

---

# 🔄 2. C2 — Conversion (Data-to-Information Level)

## 🎯 Role
Transform raw data → structured information  

## 🔧 Functions
- Data processing  
- Feature extraction  
- Data modeling  
- Data harmonization  

## 📜 Key Standards
- IEC 61804 (EDDL)  
- IEC 61360  
- IEC 62714 (AML)  
- ISO/IEC 13236  
- ISO 27000  
- IEC 62443  

## 🧠 Insight
- Data consistency & interoperability  
- Secure processing  

---

## 📜 Key Standards

- IEC 61158 / 61784  
- IEC 62591 / 62601  
- ISO/IEC 14476  
- ISO/IEC 17826

## 🧠 Insight

- Connects systems  
- Enables real-time CPS

# 🔁 Unified View

| 5C Layer | CPS Function | Standard Focus |
|----------|-------------|----------------|
| C1 | Sensing | Sensors, PLC |
| C2 | Processing | Data & security |
| C3 | Cyber | Networks & cloud |
| C4 | Intelligence | Monitoring |
| C5 | Action | Control |

---

# 🧠 Key Takeaways

### 1. Layer-Specific Standards
Each layer has distinct standard families  

### 2. Multi-Domain Integration
- IT (ISO/IEC)  
- Automation (IEC)  
- Communication (IEEE)  

### 3. Communication Backbone
C3 enables full CPS integration  

### 4. Cross-Layer Security
- Data → ISO 27000  
- Network → ISO 27033  
- Industrial → IEC 62443  

### 5. Closed-Loop CPS

Sense → Process → Model → Decide → Act → Repeat  

---

# 🚀 Final Insight

CPS standardization is **fragmented but complementary**, and mapping them to the 5C architecture provides a **unified engineering framework**.
