# 🧩 Standard Collection Based on the 5C Architecture

## 📘 Concept

The part organizes international CPS standards according to the 5C architecture:

**Connection → Conversion → Cyber → Cognition → Configuration**

👉 This creates a layered standard ecosystem, where each level:
- has a specific technical role, and  
- is supported by dedicated standards  

✔ Ensures interoperability, scalability, and industrial implementation in Industry 4.0  

---

# 🏛️ 1. C1 — Connection (Smart Connection Level)

## 🎯 Role
Acquire data from the physical world (machines, sensors, devices)

## 🔧 Functions
- Sensors & actuators  
- Data acquisition  
- Device identification  
- PLC-based control  

## 📜 Key Standards
- ISO/IEC 19762 — Information Technology – Automatic Identification and Data Capture (AIDC) Techniques – Harmonized Vocabulary  
- ISO/IEC 15459 — Information Technology – Unique Identification for Items (UID)  
- ISO/IEC/IEEE 21450 — Smart Transducer Interface for Sensors and Actuators – Common Functions, Communication Protocols, and TEDS  
- ISO/IEC/IEEE 21451 (Series) — Smart Transducer Interface for Sensors and Actuators  
- IEC 61131 — Programmable Controllers (PLC) – Programming Languages and Requirements  
- IEC 61499 — Distributed Control Systems Using Function Blocks  
---
## 🧠 Insight
Data entry point of CPS:
- Real-time sensing  
- Standardized communication  

---

# 🔄 2. C2 — Conversion (Data-to-Information Level)

## 🎯 Role
Transform raw data → structured information  

## 🔧 Functions
- Data processing  
- Feature extraction  
- Data modeling  
- Data harmonization  

## 📜 Key Standards 
- IEC 61804 (Series) — Electronic Device Description Language (EDDL)  
- IEC 61360 (Series) — Standard Data Element Types for Electric Components  
- IEC 62714 — Automation Markup Language (AML)  
- ISO/IEC 13236 — Information Technology – Quality of Service Framework  
- ISO/IEC 27000 (Series) — Information Security Management Systems (ISMS)  
- IEC 62443 (Series) — Industrial Communication Networks – Cybersecurity  

---
## 🧠 Insight
- Data consistency & interoperability  
- Secure processing  

---

- ISO/IEC 14476 — Enhanced Communications Transport Protocol (QoS)  
- ISO/IEC 17826 — Cloud Data Management Interface (CDMI)  
- ISO/IEC 27033 — Network Security Standards  
- IEC 62769 — Field Device Integration (FDI)  

--- 

## 🧠 Insight

- Connects systems  
- Enables real-time CPS

# 🔁 Unified View

| 5C Layer | CPS Function | Standard Focus |
|----------|-------------|----------------|
| C1 | Sensing | Sensors, PLC |
| C2 | Processing | Data & security |
| C3 | Cyber | Networks & cloud |
| C4 | Intelligence | Monitoring |
| C5 | Action | Control |

---

# 🧠 Key Takeaways

### 1. Layer-Specific Standards
Each layer has distinct standard families  

### 2. Multi-Domain Integration
- IT (ISO/IEC)  
- Automation (IEC)  
- Communication (IEEE)  

### 3. Communication Backbone
C3 enables full CPS integration  

### 4. Cross-Layer Security
- Data → ISO 27000  
- Network → ISO 27033  
- Industrial → IEC 62443  

### 5. Closed-Loop CPS

Sense → Process → Model → Decide → Act → Repeat  

---

# 🚀 Insight

CPS standardization is **fragmented but complementary**, and mapping them to the 5C architecture provides a **unified engineering framework**.
