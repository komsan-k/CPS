# Agentic AI vs Physical AI  
## Toward Cyber-Physical Intelligence

---

## 1. Agentic AI (Decision-Centric Intelligence)

### Definition
Agentic AI refers to AI systems that behave like **autonomous agents** capable of:

- Perceiving
- Reasoning
- Planning
- Acting
- Learning from feedback

### Core Idea
**AI that can decide what to do next**

### Architecture Loop
Perception → Reasoning → Planning → Action → Feedback

### Key Features
- Goal-oriented behavior
- High autonomy
- Tool usage (APIs, databases)
- Memory (short + long term)
- Multi-agent collaboration

### Examples
- AI copilots
- Autonomous planning systems
- Multi-agent simulations
- LLM + tools (Node-RED + AI)

---

## 2. Physical AI (Embodied Intelligence)

### Definition
Physical AI refers to AI systems that interact with the **real world** via:

- Sensors (input)
- Actuators (output)

### Core Idea
**AI that senses and acts in the real world**

### Architecture Loop
Sensor → AI Model → Control → Physical System → Feedback

### Key Features
- Real-time operation
- Edge deployment (ESP32, FPGA)
- Closed-loop control
- Physics integration
- Digital twin sync

### Examples
- Self-driving systems
- Smart lighting (LDR + TinyML)
- Metasurface beam control
- ESP32 CPS labs

---

## 3. Key Differences

| Aspect | Agentic AI | Physical AI |
|---|---|---|
| Focus | Decision-making | Real-world interaction |
| Environment | Digital | Physical |
| Loop | Cognitive | Control |
| Input | Data | Sensors |
| Output | Decisions | Actuation |
| Timing | Flexible | Real-time |
