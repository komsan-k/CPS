## 📌 Overview

This repository presents a research-grade taxonomy of Artificial
Intelligence (AI) algorithms aligned with:

-   Cyber-Physical Systems (CPS) Architecture
-   ISO/IEC 30141 IoT Reference Model
-   5C Intelligent Manufacturing Architecture
-   Physical AI & Intelligent Control Pipelines

The objective is to bridge traditional AI taxonomy with real-world CPS
implementation layers.

------------------------------------------------------------------------

## 🧭 CPS-Oriented Intelligent Pipeline

Traditional AI: Sense → Data → Model → Prediction

→ Optimize → Adapt

| **Unsupervised Learning** | k-Means, DBSCAN, PCA, t-SNE | Perception | Service | Pattern discovery |
| **Probabilistic Models** | Naive Bayes, MDP | Cognition | Application | Uncertainty reasoning |
