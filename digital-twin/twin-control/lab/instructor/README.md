# Lab: RSSI-Based Twin-Control Beam Steering with ESP32 (Instructor)

## 1. Teaching Purpose
This lab demonstrates Twin-Control applied to beam steering antennas using RSSI feedback.
Students experience how sensing enables adaptive control in Cyber-Physical Systems.

---

## 2. Key Concepts to Emphasize
- Digital Twin as a decision-support entity
- RSSI as a physical performance proxy
- Closed-loop control vs open-loop configuration

---

## 3. Reference Configuration
- Number of beams: 16
- Beam hold time: 250 ms
- RSSI samples per beam: 20
- Selection metric: average or median RSSI
- Rescan interval: 3–5 seconds

---

## 4. Assessment Rubric (10 Marks)
Implementation: 3
Sensing: 2
Control Logic: 3
Explanation: 2

---

## 5. Instructor Notes
- LED arrays can emulate beam states
- Suitable for CPS, Antennas, IoT, and Smart RF courses
